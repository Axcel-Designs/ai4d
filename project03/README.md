# Prompt Chaining using LCEL

building an intelligent software requirements analysis system for a technology consulting company.

Clients often submit project ideas as unstructured text. Before a project can be estimated or assigned to a development team, the requirements need to be analyzed, categorized, clarified, and summarized.

The first stage of implementation is to design and implement a prompt chain using LangChain LCEL (LangChain Expression Language) that processes a client's free-text project description step by step to understand the requested system and prepare an initial project assessment.

**prompt chain have 5 clearly defined prompts that accomplish the following:**

1. **Interpret the Project Request:** Understand the client's project description and identify the main business objective.
2. **Identify Possible Project Categories:** Suggest one or more categories that might apply to the project.
3. **elect the Best Category:** Choose the most appropriate category based on the client's requirements.
4. **Extract Missing Requirements:** Identify important information that is missing and would be required before implementation can begin.
    Examples:
      - Target users
      - Platform (Web, Mobile, Desktop, API)
      - Authentication requirements
      - Integration requirements
      - Data storage requirements
      - Performance or scalability requirements
5. **Generate an Initial Assessment:** Produce a short project assessment that includes:
      - Selected category
      - Summary of the client's request
      - Missing information
      - Recommended next steps

Each stage builds on the previous one, forming a logical reasoning chain from:

```md
Understanding → Classification → Validation → Requirement Extraction → Assessment
```

## Available Categories

All project requests must be classified into one of these categories:

- Web Application
- Mobile Application
- API / Backend Service
- Data Analytics Platform
- AI / Machine Learning System
- E-Commerce Platform
- Enterprise Management System
- System Integration
- DevOps / Infrastructure Automation
- General Software Project
